# Demo 與驗收

## 無金鑰展示（約五分鐘）

1. 說明 MediaTek 情境，課程題目非官方題庫。
2. 設定履歷與職缺，選示範模式、3 題。
3. 回答專案經驗、展示追問；下一題修改 C++ 邊界條件。
4. 暫停並重新整理，展示草稿、程式與進度保留；繼續完成。
5. 回顧、重答、匯出 Markdown；說明關鍵詞只是字面檢查。
6. 下載完整備份，在另一個本機埠或電腦還原，展示續練與歷史。

## 設定金鑰後實測

- 確認模型權限與額度，短背景、3 題做一次 GPT 出題。
- 回答 → GPT 追問 → 生成回饋 → 重答比較，核對引用原文。
- 連接語音並允許麥克風，聽題目、開始／結束回答，確認逐字稿與唯一一次追問。
- 回答追問後等候文字完成，再換題；確認重新整理後錄音可播。
- 測試拒絕麥克風、斷線、額度不足。失敗不得偷偷改成假 AI 結果。
- 記錄延遲、誤字、實際用量與費用。錄音取得參與者同意。

## 自動檢查

`npm test` 全部使用離線 mock，涵蓋規則、Responses 格式與引文、授權、去重／重試、Realtime 取消及錄音保存、備份完整性。測試不會使用 API 額度，也不能證明真實服務或麥克風一定能用。

ZIP 解壓後 `npm run verify:handoff`，再 `npm test`、`npm start`。自行修改檔案後雜湊不一致是預期，請重新打包。

## 老師可能追問

- 和 ChatGPT 差別：固定面試流程、題目快照、程式作答、引用回饋、重答比較、可移轉紀錄。
- 為何無 RAG：目前使用背景與明確問題，沒有外部知識庫需求。
- 如何判斷正確：引文只驗來源，技術內容人工核對，程式未執行；未來可加測試環境。
- 語音完成程度：整合與離線測試完成，真實語音需設定金鑰後驗證。
- 資料位置：瀏覽器保存，GPT 模式將必要輸入傳 OpenAI，備份負責移轉，沒有雲端同步。
- 多人使用：各瀏覽器資料獨立，無公開服務所需的全域配額與帳戶系統。
